两个版本是同一份代码。Pro 在 Kitewell 之上增加可选模块，不会改变核心的工作方式。按你的产品现在需要的功能来选择。

## 两个版本都包含的

[Kitewell 是什么](/start/introduction)中列出的全部内容：邮箱、魔法链接、Google 和 GitHub 登录；带角色和邀请的组织；带套餐限额的 Stripe 计费；通过 SMTP 或 Resend 发送邮件；后台任务；产品外壳；营销网站；英语和中文；以及测试。

## Kitewell Pro 增加的

| 模块       | 增加的功能                                                         |
| ---------- | ------------------------------------------------------------------ |
| 账号安全   | 两步验证登录、通行密钥、已登录设备、更换邮箱、安全提醒邮件         |
| 管理后台   | 位于 `/admin` 的运营人员后台：搜索、封禁、以用户身份登录、操作日志 |
| 企业登录   | Microsoft、Apple 以及任意 OpenID Connect 提供商                    |
| Paddle     | Paddle 计费：代收商户（merchant of record）、支付宝订阅、优惠码    |
| 试用与席位 | 带提醒邮件的免费试用；按成员计费的订阅                             |
| 上传       | 头像、组织 Logo 和附件，存储在兼容 S3 的存储或本地                 |
| 活动记录   | 设置 > 活动记录：谁做了什么，支持筛选和导出 CSV                    |
| API        | API 密钥和带速率限制的公开 REST API（`/api/v1`）                   |
| Webhooks   | 设置 > Webhooks：签名的事件推送，带重试和投递记录                  |
| 用量计费   | 按量计费的 API 请求、额度包和超额计费                              |
| 单点登录   | 按组织的 SAML、SCIM，以及强制两步验证或 SSO                        |

每个模块都是可选的：项目可以[去掉](/pro/modules)用不到的模块。

## 如何选择

- **Kitewell** 适合这样的产品：需要登录、团队和订阅，其余部分你自己构建。它免费且开源。
- **Kitewell Pro** 适合这样的情况：你的客户期待上面这些模块提供的功能，例如企业客户要求单点登录、API 或审计记录，或者你通过 Paddle 销售。自己实现这些功能需要数周时间，而且每一项都有需要做对的安全细节。

你可以先用 Kitewell，之后再升级到 Pro：Pro 就是 Kitewell 加上模块，你自己写的功能可以直接带过去。
